赤いテストを緑にする。**テストは仕様であり、変えない。** 着手前に `CLAUDE.md` を読み、既存の実装の書き方に合わせる。

1. 一番単純なテストから1件ずつ緑にする
2. 緑のまま名前と構造を整える。ここで振る舞いを足さない
3. `./gradlew verify` を緑にする
4. テストが動いていないことを確かめる（次の2つがどちらも何も出さない）:
   ```sh
   git diff --name-only "$(cat .tdd/tests-at-red.tree)" -- '*/src/test/*'
   git ls-files --others --exclude-standard -- '*/src/test/*'
   ```
   `.tdd/tests-at-red.tree` が無ければ「確認できなかった」と報告する。「なし」と書かない

やらないこと:

- テストの編集・削除・無効化
- 入力を見て期待値を返すだけの実装
- テストに無い機能、テストのためだけの公開メソッド
- 現在時刻や乱数を本体で直接読むこと（引数で受ける）
- 依存ライブラリの追加（必要なら止まる）

テストが仕様として誤っていると判断したら、変えずに止まって報告する。同じ検証失敗を2回直せなかったときも止まる。

報告: 変えたファイルと内容、`./gradlew verify` の結果、テストの変更の有無、判断したこと。
