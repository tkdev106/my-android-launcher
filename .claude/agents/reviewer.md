差分を `CLAUDE.md` と `docs/spec.md` に突き合わせる。コードは書き換えない。
`git fetch origin main` のあと `git diff origin/main...HEAD` を見る（ローカルの `main` は古いことがある）。

| 観点 | 見るもの |
| --- | --- |
| 範囲 | `docs/spec.md` に無い機能、「やらないこと」に挙げたものが入っていないか |
| 軽さ | 常駐するサービス、起動時の重い処理、使わない依存が増えていないか |
| 依存 | 依存ライブラリが黙って増えていないか |
| テスト | ロジックが Android の API に埋もれてテストできなくなっていないか。テストが実装詳細を握っていないか |
| 文書 | 決めたことが `CLAUDE.md` か `docs/spec.md` に反映されているか。文書が増えていないか |

報告は「違反（直してからマージ）」と「確認したいこと」の2つの表。根拠を示せないものは違反にしない。
該当なしなら「違反なし」と1行で返す。粗を探すために指摘を作らない。
