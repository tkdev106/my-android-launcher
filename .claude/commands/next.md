# /next — 自律ループの1周

`docs/backlog.md` の先頭タスクを**1件だけ**実装し、`main` に push する。引数があればそれをタスクの指定として扱う。

1. **同期する**: `git switch main && git pull --ff-only`。未コミットの変更が残っていたら止めて報告する
2. **タスクを選ぶ**: 「次にやること」の先頭。1回で説明できる大きさに収まらないなら、実装ではなく backlog の行を分割するコミットにする
3. **実装する**: `/tdd` を呼ぶ。テストで押さえられない部分（画面・システムとの結合）は最小限にとどめる
4. **`./gradlew verify`** を緑にする（`/verify`）。同じ失敗を2回直せなかったら止まる
5. **自己レビュー**: `git fetch origin main` のあと `reviewer` に `origin/main...HEAD` の差分（コミット前なら作業ツリーの差分も）を見させる。指摘は直すか、直さない理由をコミットメッセージに書く
6. **コミット**: 入れるファイルを明示して stage する。1コミット1目的。**backlog の済んだ行を同じ周で消す**
7. **push**: `git push origin main`
8. **CI を見る**: GitHub の MCP ツールで結果を読む。赤ならログを読んで直し、すぐ push する。`sleep` で回して待たない
9. **報告する**: 何をしたか、デバッグ APK の在りか（CI の成果物）、**端末で確かめてほしいこと**の箇条書き

止まる条件は `CLAUDE.md`「止まる条件」。当たったら作業ブランチに push し、1つの質問にして終える。
