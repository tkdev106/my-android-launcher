# 自作ランチャー 仕様（Nova Launcher 8.2.4 のバックアップから起こしたもの）

目的: Nova で実際に使っている機能だけを再現し、Nova より軽いホームアプリにする。自分の端末専用（Pixel 7 / Android 17 / 2400×1080 / 420dpi）。Play ストアには出さない。

## 作り方

- 素の Android View（AndroidX も Compose も使わない）。依存は Kotlin 標準ライブラリだけにして、起動とメモリを最小にする
- minSdk = targetSdk = Android 17 の API。古い版への分岐を持たない
- ホームのアプリ・ドック・ドロワーのフォルダ・アイコンの差し替えは、アプリ内部の JSON ファイル1つに保存する（Room 等を足さない。そのままバックアップにもなる）
- 常駐するのは次の2つだけ
  - ユーザー補助サービス（ジェスチャーのうち、最近使ったアプリ・通知・クイック設定・画面を消すに使う）
  - 通知へのアクセスのサービス（再生中の曲を読むためだけに使い、通知そのものは扱わない）

## やらないこと

- Google フィード（左のページ）
- ページの追加・ページ一覧表示（ホームは1ページ固定）
- 通知バッジ、アイコンパック、予測表示、ドロワーのタブ、スクロール効果
- 多機能な設定画面
- 他のアプリのウィジェットを置くこと、ホームの配置を自由に動かすこと（配置は下の固定レイアウト）

## ホーム画面（1ページ・配置は固定）

デザインは H 案（https://claude.ai/artifact/N3rmySib64ggkjfhEM9N1z の「H」）。上から順に次を置く。

1. 時計: 時刻を大きく、その下に日付
2. 天気: 今日は大きなアイコンと気温。明日・明後日は最低〜最高気温を線の長さで比べる
3. 予定一覧: 小さめの字で3件まで
4. 余白（壁紙を見せる）
5. 再生中の曲
6. アプリ4つ: LINE / X / Chrome / YouTube（`app.revanced.android.youtube`）。ラベルなし
7. ドック

文字は壁紙の上に直接置き、薄い影で読めるようにする。アイコンの丸には暗い半透明の下地を敷く。

### 内蔵パネル（他のアプリのウィジェットの代わりにランチャーが自分で描く）

- 時計: 日付と時刻。表記は英字。時刻の書体は Instrument Serif
- 天気: 気象庁の予報データ。今日から3日分の天気・最高/最低気温・降水確率。表記は英字。ホームを開いたときに古ければ取り直し、常駐しない
  - 地域は端末が最後に取った大まかな位置（おおよその位置情報の許可）から市区町村を引き、気象庁の予報区域に当てる。位置が取れないときは東京地方
- 予定一覧: 端末のカレンダー（Google カレンダーの同期分）を読む。今日から3日分。タップでその予定を Google カレンダーで開く
- 再生中の曲: 再生中のプレーヤー（主に Apple Music）のジャケットを大きめに、右に曲名・アーティスト名（横書き）と再生/一時停止ボタンだけを置く。ジャケットのタップでそのプレーヤーを開く。何も再生していないときは Apple Music を開くボタンにする

## ドック（5列、3つ）

1. 1列目: フォルダ「決済」PayPay / 楽天ペイ / Google ウォレット（カード柄のカスタムアイコン）
2. 3列目: アプリ一覧を開くボタン（点9個のカスタムアイコン）
3. 5列目: フォルダ「AI」Claude / Muse

2・4列目は空ける。

## アプリ一覧（ドロワー）

- 横にページをめくる形式、6列×7行、上に検索バー。背景は透明で壁紙がそのまま見える（アイコンの丸に暗い下地を敷いて読めるようにする）
- アイコンだけを並べ、アプリ名は出さない。フォルダの丸には中のアプリの小さなアイコンを並べて見分ける
- フォルダを先頭に並べる: Entertainment / Finance / Food / Games / Shopping / Social / Travel
- フォルダに入れたアプリは一覧本体から隠す
- 並びは名前順（英字 → かな）
- 検索はアプリ名の部分一致。フォルダに入ったアプリも結果に出す
- 新しく入れたアプリはドロワーに出るだけで、ホームには何も足さない
- フォルダの中身は Nova のバックアップの値を初期値にする（別ファイル）

## ジェスチャー

| 操作 | 動作 |
| --- | --- |
| 上へスワイプ / 2本指で下へ | アプリ一覧 |
| 下へスワイプ | 通知を開く |
| ピンチアウト | 最近使ったアプリ（ユーザー補助の `GLOBAL_ACTION_RECENTS`） |
| 2本指で上へ | 編集モード（設定画面） |
| ダブルタップ | 画面を消す（ユーザー補助の `GLOBAL_ACTION_LOCK_SCREEN`） |
| ピンチイン | クイック設定を開く（ユーザー補助の `GLOBAL_ACTION_QUICK_SETTINGS`） |

## 編集モード（最小限の設定画面）

- ホームのアプリ4つと、ドックのフォルダの中身の入れ替え
- ドロワーのフォルダの編集
- 個別アイコンの差し替え

## 見た目

- 常にダーク、縦画面固定、壁紙はスクロールしない
- フォルダのアイコンは円形、フォルダは窓で開く
- モノクロ基調で統一する。アイコンはホーム・ドック・ドロワーとも同じ大きさの丸に、白い単色の絵柄を置く
- ホーム・ドックのアイコンは線の太さを揃えた自作の絵柄。ドロワーは各アプリの単色版アイコン（Android の themed icon）を使い、無いアプリは元のアイコンを白黒にして同じ丸に収める
