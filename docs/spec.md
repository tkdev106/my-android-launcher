# 自作ランチャー 仕様（Nova Launcher 8.2.4 のバックアップから起こしたもの）

目的: Nova で実際に使っている機能だけを再現し、Nova より軽いホームアプリにする。自分の端末専用（Pixel 7 / Android 17 / 2400×1080 / 420dpi）。Play ストアには出さない。

## 作り方

- 素の Android View（AndroidX も Compose も使わない）。依存は Kotlin 標準ライブラリだけにして、起動とメモリを最小にする
- minSdk = targetSdk = Android 17 の API。古い版への分岐を持たない
- ホームのアプリ・ドック・ドロワーのフォルダ・アイコンの差し替えは、アプリ内部の JSON ファイル1つに保存する（Room 等を足さない。そのままバックアップにもなる）
- 常駐するのは次の2つだけ
  - ユーザー補助サービス（ジェスチャーのうち、最近使ったアプリ・通知・クイック設定・画面を消すに使う）
  - 通知へのアクセスのサービス（再生中の曲を読むためだけに使い、通知そのものは扱わない）

## やらないこと

- Google フィード（左のページ）
- ページの追加・ページ一覧表示（ホームは1ページ固定）
- 通知バッジ、アイコンパック、予測表示、ドロワーのタブ、スクロール効果
- 多機能な設定画面
- 他のアプリのウィジェットを置くこと、ホームの配置を自由に動かすこと（配置は下の固定レイアウト）
- ロック画面の時計（Android の決まりで、ホームアプリからは変えられない）

## ホーム画面（1ページ・配置は固定）

デザインは H 案（https://claude.ai/artifact/N3rmySib64ggkjfhEM9N1z の「H」）。上から順に次を置く。

1. 時計: 時刻を大きく、その下に日付
2. 天気: 今日は大きなアイコンと今の気温。明日・明後日は最低〜最高気温を線の長さで比べる
3. 予定一覧: 小さめの字で3行の高さ（1か月先まで中をスクロールして見る）
4. 余白（壁紙を見せる）
5. 再生中の曲
6. アプリ4つ: LINE / X / Chrome / YouTube（`app.revanced.android.youtube`）。ラベルなし
7. ドック

文字は壁紙の上に直接置き、薄い影で読めるようにする。アイコンの丸には暗い半透明の下地を敷く。

### 内蔵パネル（他のアプリのウィジェットの代わりにランチャーが自分で描く）

- 時計: 日付と時刻。表記は英字。時刻の書体は Instrument Serif
- 天気: 気象庁の予報データ。今日から3日分の天気・最高/最低気温・降水確率。表記は英字。ホームを開いたときに前に取ってから1時間以上たっていれば取り直し、常駐しない
  - いちばん大きく出すのは今の気温（気象庁のアメダスの最新の観測。10分以上たっていれば取り直す）。取れないときは今日の最高気温
  - タップで Yahoo!天気を開く（アプリが無ければ Web）
  - 地域は端末が最後に取った大まかな位置（おおよその位置情報の許可）から市区町村を引き、気象庁の予報区域に当てる。位置が取れないときは東京地方
- 予定一覧: 端末のカレンダー（Google カレンダーの同期分）を読む。今日から1か月分。行の頭にその予定のカレンダーの既定の色の丸を置く（家族と自分のカレンダーを見分ける）。行のタップでその予定を、それ以外のタップで Google カレンダーを開く。1週間より先は曜日でなく日付で書く。許可が無いときは許可を求める1行、予定が無いときは「No events」の1行を出す
- 再生中の曲: 再生中のプレーヤー（主に Apple Music）のジャケットを大きめに、右に曲名・アーティスト名（横書き）と再生/一時停止ボタンだけを置く。ジャケットのタップでそのプレーヤーを開く。何も再生していないときは Apple Music を開くボタンにする。通知へのアクセスが無いときは、その許可の画面を開くボタンにする

## ドック（5列、3つ）

1. 1列目: フォルダ「決済」PayPay / 楽天ペイ / Google ウォレット（カード柄のカスタムアイコン）
2. 3列目: アプリ一覧を開くボタン（点9個のカスタムアイコン）
3. 5列目: フォルダ「AI」Claude / Muse（Muse はパッケージ名が分からないので、初回にアプリ名で探す）

2・4列目は空ける。

## アプリ一覧（ドロワー）

- 横にページをめくる形式、6列×7行、上に検索バー。最後のページの先は最初のページ、最初のページの手前は最後のページにつながる。背景は壁紙だけ（開いている間はホームの中身を隠す。アイコンの丸に暗い下地を敷いて読めるようにする）
- アイコンだけを並べ、アプリ名は出さない。フォルダの丸には中のアプリの小さなアイコンを並べて見分ける
- アプリを勝手にフォルダにまとめない。フォルダは編集モードで作ったものだけ（初期値は無し）で、名前順に先頭に並べる
- フォルダに入れたアプリは一覧本体から隠す
- 並びは名前順（英字 → かな）
- 検索はアプリ名の部分一致（大文字小文字・全角半角・ひらがなとカタカナを区別しない）。先頭が一致するものを前に出す。フォルダに入ったアプリも結果に出す
- 新しく入れたアプリはドロワーに出るだけで、ホームには何も足さない
- アイコンを長押しすると、そのアプリの「アプリ情報」の設定画面を開く（アンインストールのため。メニューは挟まない）

## ジェスチャー

| 操作 | 動作 |
| --- | --- |
| 上へスワイプ / 2本指で下へ | アプリ一覧 |
| 下へスワイプ | 通知を開く |
| ピンチアウト | 最近使ったアプリ（ユーザー補助の `GLOBAL_ACTION_RECENTS`） |
| 2本指で上へ | 編集モード（設定画面） |
| ダブルタップ | 画面を消す（ユーザー補助の `GLOBAL_ACTION_LOCK_SCREEN`） |
| ピンチイン | クイック設定を開く（ユーザー補助の `GLOBAL_ACTION_QUICK_SETTINGS`） |

予定一覧がスクロールできる間は、その上で始めた1本指の操作は予定一覧のスクロールにする。

## 編集モード（最小限の設定画面）

- ホームのアプリ4つと、ドックのフォルダの中身の入れ替え
- ドロワーのフォルダの編集
- 個別アイコンの差し替え
- 許可の入口（ユーザー補助・通知へのアクセス・カレンダーと位置情報）

## 見た目

- 常にダーク、縦画面固定、壁紙はスクロールしない（横長の壁紙は真ん中を見せる）
- フォルダのアイコンは円形。フォルダは押したアイコンのすぐそばに窓で開き、中身を全部見せる。窓にフォルダ名は出さない
- モノクロ基調で統一する。アイコンはホーム・ドック・ドロワーとも同じ大きさの丸に、白い単色の絵柄を置く
- 書体は時計・気温・再生中の曲名とアーティスト名が Instrument Serif、本文が Geist、日付・曜日などの小さな英字が Geist Mono（H 案のとおり。日本語は端末の書体）
- ホーム・ドックのアイコンと、決済・AI のフォルダの中のアプリ（PayPay / 楽天ペイ / Google ウォレット / Claude / Muse）は線の太さを揃えた自作の絵柄。元のロゴの特徴（Chrome の3つの区切り、PayPay の楕円の帯と斜めの縦線でできた P、楽天の R と、左が尖って右上がりに細くなる帯、ウォレットの重なったカード、Claude の不揃いな光の筋、Muse の一筆書きの M）を少し残す。ドロワー（ドロワーのフォルダとその中も含む）では、これらのアプリも自作の絵柄を使わず、ほかのアプリと同じく各アプリの単色版アイコン（Android の themed icon）を使い、無いアプリは元のアイコンから地の色と違う部分（ロゴ）を抜き出して、白い絵柄として同じ暗い丸に収める。丸からはみ出す絵柄は縮めて真ん中に置く
